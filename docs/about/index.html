AI 키는 받아 가는 사람 것

만든 사람 계정을 쓰지 않는다. 각자 자기 Claude Code나 자기 API 키로 돌린다.

파일은 내 컴퓨터에만

서버가 따로 없다. 만든 발표자료가 다른 사람에게 올라가지 않는다.

바깥으로 나가는 통신 없음

만들어진 HTML과 PPTX에는 외부 주소가 없다. 열어도 어디에도 연결하지 않는다.

내 컴퓨터에서만 열린다

서버는 127.0.0.1에만 붙는다. 같은 와이파이를 쓰는 사람도 들어오지 못한다.

쓰려면

macOS 기준이다. Node 18 이상과 Claude Code가 있어야 한다.

# 1. 내려받기
git clone https://github.com/hy0909/ppt-maker.git
cd ppt-maker

# 2. 글꼴 설치 (Pretendard · Paperlogy, 둘 다 무료)
./install_fonts.sh

# 3. 내 AI 키 넣기
export ANTHROPIC_API_KEY=내-키

# 4. 켜기
./start.sh
글꼴. Pretendard와 Paperlogy는 OFL이라 누구나 공짜로 쓸 수 있다. 설치 스크립트가 공식 배포처에서 받아 넣는다.
