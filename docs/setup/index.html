AI 연결하기

글을 읽고 장표 구성을 짜는 일만 AI 에 맡긴다. 내 계정으로 돌고, 요금도 내 계정으로 나간다. 만든 사람의 키는 어디에도 들어 있지 않다.

앱 화면으로 GitHub 저장소

셋 중 하나만 고르면 된다

서버는 켤 때 준비된 것을 알아서 고른다. Claude API 키, GPT API 키, Claude Code 순서다.

방법키가 필요한가이럴 때 고른다
Claude Code없어도 된다Claude 구독이 있다. 가장 간단하다
Claude API 키필요하다쓴 만큼 내고 싶다
GPT API 키필요하다OpenAI 를 쓴다. 같은 방식의 다른 서비스도 된다

1. Claude Code — 키 없이

Claude 구독이 있으면 이게 제일 쉽다. 터미널에 한 번만 로그인해 두면 된다.

npm install -g @anthropic-ai/claude-code
claude auth login
./start.sh

화면 오른쪽 위에 Claude Code CLI 라고 뜨면 연결된 것이다. 모델을 바꾸려면 PPT_MAKER_CLI_MODEL=sonnet 을 앞에 붙인다.

2. Claude API 키

console.anthropic.com 에서 키를 만든다. sk-ant- 로 시작한다.

ANTHROPIC_API_KEY=sk-ant-여기에-내-키 ./start.sh

매번 치기 번거로우면 ~/.zshrc 에 적어 둔다.

echo 'export ANTHROPIC_API_KEY=sk-ant-여기에-내-키' >> ~/.zshrc
source ~/.zshrc

3. GPT API 키

platform.openai.com/api-keys 에서 키를 만든다. sk- 로 시작한다.

OPENAI_API_KEY=sk-여기에-내-키 ./start.sh

OpenAI 말고 다른 곳

OPENAI_BASE_URL 을 바꾸면 OpenAI 와 같은 방식으로 말하는 곳은 다 붙는다. Azure OpenAI, Together, Groq, 내 컴퓨터에서 돌리는 Ollama 나 LM Studio 같은 것들이다.

# 내 컴퓨터의 Ollama
OPENAI_BASE_URL=http://localhost:11434/v1 \
OPENAI_API_KEY=ollama \
PPT_MAKER_OPENAI_MODEL=qwen2.5:32b ./start.sh
서비스마다 받는 항목이 조금씩 다르다. 새 항목을 모르는 곳이면 서버가 알아서 기본 항목만 다시 보낸다. 따로 손볼 것이 없다.

4. 아무것도 연결하지 않고 쓰기

키도 구독도 없이 쓰는 길이 하나 더 있다.

장표 구성 화면에서 프롬프트 복사를 누르고, 그 내용을 쓰던 AI 에 붙여 넣는다. 받은 JSON 을 JSON 붙여넣기로 가져오면 그다음부터는 평소와 똑같이 돌아간다. 웹에 올라간 둘러보기 화면에서도 이 길은 열려 있다.

요청 한도를 넘었습니다조금 기다린다

서버를 켠 터미널에 더 자세한 내용이 찍힌다.

내가 만든 파일이 남에게 보이나

보이지 않는다. 서버는 각자 자기 컴퓨터에서 돌고, 만든 파일도 그 컴퓨터에만 남는다.

서버는 127.0.0.1 에만 붙어서 같은 공유기를 쓰는 사람도 들어오지 못한다. 다른 기기에서 열려면 HOST=0.0.0.0 을 직접 줘야 하는데, 이 서버에는 로그인이 없다. 들어온 사람이 내 AI 사용량을 그대로 쓰니 필요할 때만 켜고 바로 되돌리는 편이 안전하다.
