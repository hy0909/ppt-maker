표지 배경

ppt-maker가 실제로 그리는 값이다. 좌표·크기·색은 scripts/lib/common.mjs와 build_html.mjs에서 그대로 가져왔다. 값을 고치면 오른쪽 장표가 바로 바뀐다. 표지 배경과 로고는 실제 파일을 가져와 보여 준다. 간지 워터마크처럼 문서마다 달라지는 그림만 점선 자리로 둔다.

고친 값을 남기는 길은 세 가지다. 내 컴퓨터의 ppt-maker 앱에서 열었으면 저장이 skills/ppt-maker/design-tokens.json 을 바로 고친다. 웹 주소에서 열었으면 관리자 로그인을 거쳐 저장을 누른다. 저장소의 같은 파일이 바뀌고, 내 컴퓨터에서 git pull 을 받으면 다음 빌드부터 그 값으로 만들어진다. 파일로 받기는 어디서나 된다. 내려받은 파일을 skills/ppt-maker/ 에 덮어도 결과는 같다.

판 규격

모든 장표에 똑같이 걸린다. 가로는 늘 1200px 이고 세로만 리드 줄 수에 따라 네 가지로 움직인다 — 리드 1줄 262 → 414 리드 2줄 286 → 390 리드 없음 190 → 486 헤드라인 없음 96 → 580

색

메인 컬러 하나에서 나머지가 계산된다. 임의 hex를 쓰지 않는다. 보조 컬러가 흰 카드 위에서 대비 3 미만이면 메인 쪽으로 섞어 어둡게 만든다.

아래 중립색과 상태색은 메인 컬러와 상관없이 고정이다.

타이포 — 표지·목차

줄 간격과 자간이 배수가 아니라 pt 고정값이다. 읽는 방식(dense·airy)과 상관없이 늘 같다. 굵기마다 패밀리 이름이 따로 있어 bold 속성을 켜지 않는다 — 켜면 PowerPoint가 가짜 굵기를 덧씌운다.

타이포 — 본문 머리

본문 19종이 이 머리를 똑같이 쓴다. 여기도 밀도와 무관하게 고정 px이다.

타이포 — 본문 안쪽

지금은 두 방식이 같은 값을 쓴다. 보고 있는 쪽은 dense 이고, 위 스위치로 바꾼다. 한쪽만 고치면 그때부터 갈라진다.

글자 배율

fit_slides가 장표마다 본문 배율을 잰다. 빈 곳이 남으면 키우고, 넘치면 0.75까지 줄인다. 카드 안 글자·간격·알약 높이가 전부 이 배율을 따라간다. 고정 px로 그리면 안 된다.

모서리 · 그림자

테두리·채움·모서리·그림자는 "따로 떨어진 것"이라는 뜻이라 역할에 맞게만 쓴다.

템플릿 12종

판형마다 그려야 할 상태를 다 펼쳐 놓았다. 위에서 값을 고치면 여기 29장이 한꺼번에 바뀐다. 본문 판형은 머리(아이브로우·헤드라인·구분선·리드)를 똑같이 쓰고 본문 시작 y 아래만 다르다. 장표를 누르면 크게 열린다. 열린 뒤에는 ← → 로 옮겨 다니고 Esc 로 닫는다.
