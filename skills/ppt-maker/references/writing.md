# 장표 글 규칙 — human-writing 적용

원본은 [hy0909/skills · human-writing](https://github.com/hy0909/skills/tree/main/human-writing) 이다. 그 스킬이 설치돼 있으면 그 규칙 전체를 따르고, 아래는 장표에 맞게 추린 요약이다. 두 경로(Claude Code 스킬 · 웹 앱 AI 생성)가 같은 파일을 읽는다.

## 0. 최우선 — 자리마다 종결이 다르다

| 자리 | 종결 | 예 |
| --- | --- | --- |
| 장표 제목(title), 카드·컬럼 제목(heading·title), 소제목(tag·sections.heading), 표 머리글·표 칸, 단계 제목, 라벨 | **명사형으로 끝낸다.** `~한다/~합니다/~이다/~했다/~된다` 금지 | `네 항목 모두 **목표치 초과 달성**`, `감지 시간`, `1분 이내` |
| 리드(lead), 불릿·항목(items), 배너 글(callout text·items), 설명(desc·text), 발표자 노트(notes) | **문장으로 쓴다.** 아래 1~4 규칙 적용 | `집계 기간은 2026년 8월 한 달이다.` |

명사형 자리에서 면제되는 것은 어미·문장 길이·리듬 규칙뿐이다. 쉬운 말(2)과 금지 표현(3)은 제목·표 칸에도 그대로 적용한다. 표 머리글은 장표에서 가장 먼저 읽히는 낱말이라 먼저 본다.

## 1. 문장 — 결론 먼저

- 리드와 배너는 첫 문장이 결론이다. 이유·배경은 뒤에.
- 한 문장에 생각 하나, 60자 안팎. 원인과 결과처럼 붙여 읽어야 하는 둘은 60자를 넘어도 잇는다.
- 접속사(`그 결과`, `이를 통해`, `따라서`, `또한`)로 잇지 않고 문장 순서로 보여 준다.
- 말투는 덱 하나에 하나. `~다`(제출·열람용 기본) 또는 `~습니다`(발표 노트). 섞지 않는다. `~어요`는 장표에 쓰지 않는다.
- 같은 카드 안 항목들은 길이와 꼴을 비슷하게 맞추되, 어미를 바꾸려고 억지로 문장을 합치거나 질문을 넣지 않는다.

## 2. 쉬운 말 — 한자어 명사구는 풀고, 일상 동사로

- `변경 범위를 명시` → `어디까지 바꿀 수 있는지 적기`. `공통 유지 기준 부재` → `무엇을 그대로 쓰는지 정해져 있지 않음`.
- 일상 동사: 활용→쓰다, 기록→적다, 변경→바꾸다, 수정→고치다, 파악→알아보다, 선별→추리다. 뜻이 달라지면 바꾸지 않는다(구분≠나누다).
- 매일 쓰는 한자어(확인·이해·전달·검토·작성·진행)는 그대로 둔다.
- 비유로 메우지 않는다: `닿다`, `걷어내다`, `뼈대`, `돌리다`, `쥐다`, `축`, `갈래` 금지. 뜻이 같은 직설 표현으로.
- 전문용어는 우리말이 있으면 바꾼다. 팀이 매일 쓰는 말(API, 토큰, 대시보드)은 그대로.
- 문장 한가운데 괄호 설명을 끼우지 않는다. 필요하면 footnote 로.

## 3. 금지 표현

| 종류 | 금지 | 대신 |
| --- | --- | --- |
| 번역투 | `~를 통해`, `~에 있어서`, `~에 의해`, `~되어지다`, `~함에도 불구하고`, `~를 가지고 있다`, `~에 대한 ~의 수행` | `~로`, `~에서`, `~가`, `~되다`, `~지만`, `~가 있다` |
| 빈 수식어 | `효율적·효과적·체계적·혁신적·획기적·원활한·강력한·다양한`, `극대화`, `매우·정말·굉장히` | 지우거나 숫자·상황으로 |
| 상투구 | `본 자료는`, `결론적으로`, `~하는 것이 중요합니다`, `~할 필요가 있다`, `핵심은 다음과 같다`, `시사하는 바가 크다` | 문장 삭제, 또는 왜 그런지 한 문장 |
| 대조 틀 | `단순한 ~가 아니라 ~다`, `~뿐만 아니라 ~도` | 주장 하나만 |
| 나열 틀 | `첫째·둘째·셋째`, 형용사·명사 3개 나열, 모든 항목을 같은 어미·길이로 기계적으로 맞춤 | 표나 카드로 구조화 |
| 접사 | `-적`, `-성`, `-화` 남발 | 절반으로 |
| 형식명사 | `~것이다`, `~점`, `~할 필요가 있다` | 동사로 끝내기 |
| 분야 전문어 차용 | `증상`, `진단`, `처방`, `병목`, `레버리지`, `허들` | 실제로 무슨 일이 벌어지는지 |

금지어라도 그 자리에서 사실을 나르면 둔다. `다양한 레이아웃이 없다`(없는 것은 다양함)는 그대로.

## 4. 구체성 — 지어내지 않는다

- `많은·크게 개선·최근`은 숫자·기간·이름으로. 원문에 없으면 **지어내지 않고** `[입력 필요: …]` 로 남긴다.
- 원문에 없는 장면·주장을 보태지 않는다. 그릴 상황이 없으면 `읽기 어렵다`처럼 직설로.
- `중요하다`, `필요하다`는 지우고 왜 그런지 한 문장.

## 적용하지 않는 것

human-writing 의 관점 규칙(§5 반론·[내 경험])과 시작 질문(§6-1 말투·소제목 묻기)은 장표에 쓰지 않는다.
