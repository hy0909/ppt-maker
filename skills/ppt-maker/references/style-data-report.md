# 데이터 리포트 스타일 — 참고 화면 17장 분석

작성일 2026-10-16. 사용자가 "이 형식으로 템플릿을 만들자"며 건넨 화면 17장을 읽고 정리했다.
아직 템플릿으로 구현하지 않았다. 구현할 때 이 문서를 기준으로 삼는다.

---

## 1. 무엇을 봤나

| 묶음 | 장수 | 생김새 |
| --- | --- | --- |
| 리서치 발표 차트 | 15 | 검정 배경, 파랑–흰 두 색, 차트 한 장에 하나 |
| 분기 도식 | 1 | 흰 배경, 가운데 상자 → 좌우 두 상자, 아래 경고 띠 |
| 브랜드 결산 | 1 | 하늘색 배경, 큰 수치 카드 + 일러스트 |

15장이 같은 틀이라 이 문서는 **리서치 발표 차트**를 기준으로 쓴다. 나머지 둘은 6절에 따로 적었다.

---

## 2. 텍스트 성향

### 2-1. 제목 — 두 종류를 가려 쓴다

| 종류 | 언제 | 끝맺음 | 본 예 |
| --- | --- | --- | --- |
| 해석형 | 숫자에서 읽어낸 결론을 말할 때 | **`~습니다` 완성 문장** | `전사적으로 엔지니어가 코드를 더 빠르게 배포하고 있습니다.` `실험 속도가 빨라졌습니다.` `소요 시간이 긴 작업일수록 더 많은 개입이 필요합니다.` |
| 이름형 | 지표를 그대로 보여 줄 때 | **명사형** | `고난도 웹 검색 내부 평가` `즉시 검색의 실제 서비스 트래픽` `MentalHealthBench` |

**이 저장소의 기존 규칙과 다른 점이다.** `writing.md` 는 제목 자리를 명사형으로 끝내라고 한다. 리서치 발표 차트는 제목 자리에서 주장을 문장으로 말한다. 두 규칙이 부딪히므로, 이 스타일을 쓸 때만 해석형 제목을 허용하고 덱 안에서 두 종류를 섞지 않는다.

해석형 제목은 숫자를 다시 적지 않는다. `7배 늘었습니다`가 아니라 `더 빠르게 배포하고 있습니다`로 쓰고, 7배는 그래프가 말한다.

### 2-2. 부제 — 재는 조건 한 줄

제목 아래 회색 한 줄에 **무엇을 어떻게 쟀는지**를 적는다. 가운뎃점으로 조건을 잇는다.

- `모델의 알려진 약점을 테스트하기 위해 수집한 고난도 웹 검색 문제`
- `답변 시작까지 걸리는 시간 · 낮을수록 좋음 · 무료 모델`
- `2026. 01 - 2026. 06 기준`

`낮을수록 좋음`처럼 **읽는 방향**을 부제에 적는 것이 이 스타일의 표시다. 값이 작아야 좋은 지표는 반드시 적는다.

### 2-3. 축 라벨 — 길어도 기준점을 적는다

축 라벨을 짧게 줄이지 않는다. 단위와 기준점을 괄호로 붙인다.

- `활성 기여자당 변경 라인 수(2025년 이전 = 1x)`
- `활성 실험자당 실험 횟수(2025년 = 1x)`
- `사람이 운영하는 문제 해결 채널의 일일 게시물`
- `사람 기준 예상 소요 시간`

배수(`1x`, `1.6×`)로 그릴 때는 **무엇을 1로 잡았는지**를 축 라벨에 넣는다. 이게 없으면 그래프를 못 읽는다.

### 2-4. 숫자는 그림 위에 직접

막대 끝과 꺾은선 점 위에 값을 적는다(`41.6%`, `53.8%`, `+198.2k`). 축 눈금을 따라 읽게 하지 않는다.

### 2-5. 글로 한 번 더 짚는 세 가지

| 무엇 | 어떻게 | 본 예 |
| --- | --- | --- |
| 차이 | 두 막대 사이 빈 곳에 짧은 주석 | `44%` 줄바꿈 `더 빠르게` |
| 기준선 | 점선에 이름표 | `2025년 이전 평균` |
| 아직 안 끝난 구간 | 빗금 막대 | 마지막 달 막대만 사선 |

### 2-6. 설명 문단이 없다

제목·부제·축 라벨·값 라벨이 전부다. 차트 옆에 해설 문단을 붙이지 않는다. 더 읽을 거리가 있으면 왼쪽 아래에 알약 버튼 하나(`방법론 보기`)로 미룬다.

### 2-7. 로고

오른쪽 위 구석에 작게, 단색으로. 제목과 같은 줄에 둔다.

## 3. 목차 골격

15장이 놓인 순서를 보면 이야기가 이렇게 흐른다.

| 단계 | 무엇을 말하나 | 본 장표 |
| --- | --- | --- |
| 1 | 능력이 올랐다 — 벤치마크 점수 | 2계열 세로 막대 |
| 2 | 빨라졌다 — 응답 시간 | 가로 막대 + 차이 주석 |
| 3 | 시간을 쓸수록 점수가 오른다 — 맞바꿈 | 2계열 꺾은선 |
| 4 | 실제로 일이 늘었다 | 시계열 막대 + 기준선 |
| 5 | 어디에 쓰나 — 용도 분해 | 분류 범례 + 누적 영역 |
| 6 | 어느 용도가 가장 늘었나 | 가로 막대 순위 |
| 7 | 사람 손이 줄었다 | 시계열 꺾은선 |
| 8 | 한계 — 긴 작업일수록 사람이 붙어야 한다 | 100% 누적 세로 막대 |
| 9 | 그래도 나아지는 중 | 다계열 꺾은선 + 오차막대 |
| 10 | 무엇으로 쟀나 — 데이터 구성 | 100% 가로 띠, 분포도 |

**성능 → 속도 → 실사용 변화 → 용도 분해 → 한계 → 개선 추세 → 측정 방법** 순서다.

눈여겨볼 두 가지.

- **한계를 뺀 자리가 없다.** 8번이 중간에 그대로 들어간다. 좋은 숫자만 늘어놓지 않는다.
- **측정 방법이 맨 뒤다.** 앞에 두면 결론이 늦어진다.

## 4. 이 저장소 블록으로 옮기면

| 참고 화면 | 쓸 블록 | 비고 |
| --- | --- | --- |
| 2계열 세로 막대 | `chart` `kind:"bar"` | 시리즈 2개, `emphasis` 로 새 모델만 강조 |
| 가로 막대 2개 | `chart` `kind:"bar"` | 가로 방향은 아직 없다(5절) |
| 2계열 꺾은선 | `chart` `kind:"line"` | 그대로 된다 |
| 시계열 막대 + 기준선 | `chart` `kind:"bar"` | 기준선·빗금은 아직 없다(5절) |
| 가로 막대 순위 | `chart` + `ranked:true` | 위계 색은 되고, 가로 방향은 안 된다 |
| 큰 수치 카드 | `cards` + `stat` | 당근 화면의 `MAU 1,000만 +` 자리 |
| 분기 도식 | `columns` 2단 + 아래 `callout` | 1번 화면 |
| 100% 가로 띠 | — | 없다(5절) |

차트는 시리즈를 1~3개로 묶는다. 참고 화면도 2계열이 가장 많다.

## 5. 지금 못 하는 것

이 스타일을 그대로 그리려면 코드를 고쳐야 하는 것들이다. 템플릿을 만들기 전에 어디까지 할지 정한다.

| 못 하는 것 | 지금 상태 |
| --- | --- |
| 검정 배경 덱 | 본문 장표 바탕이 `#E9ECF0` 로 고정이다. 덱 단위 어두운 테마가 없다 |
| 가로 막대 | `chart` 는 세로 막대와 꺾은선 두 가지뿐이다 |
| 100% 누적 막대·누적 영역 | 없다 |
| 분포도(산점도) | 없다 |
| 오차막대 | 없다 |
| 기준선 + 이름표 | 없다 |
| 빗금(추정 구간) 표시 | 없다 |
| 값 라벨 자동 표시 | 그래프마다 다르다. `design-system.md` 의 그래프 절 확인 필요 |

제목 두 종류(2-1)와 목차 골격(3)은 코드를 안 고쳐도 지금 쓸 수 있다.

## 6. 나머지 두 장

### 6-1. 분기 도식 (흰 배경)

제목이 `어디로 분화하나 — 그런데 안전지대는 없다` 다. **질문 + 줄표 + 뒤집기** 꼴이다. 가운데 상자 하나에서 좌우로 선이 갈라지고, 상자마다 색 글씨 제목과 불릿 3개가 들어간다. 맨 아래 연분홍 띠에 결론을 한 문장으로 적는다 — `'프런트로 가면 안전'은 착각 — 코드를 뽑아내는 압력은 그쪽에도 똑같이 닿는다.`

띠 글은 앞의 도식을 요약하지 않고 **반박한다.** 도식이 두 길을 보여 주면 띠는 "둘 다 안전하지 않다"고 적는다.

### 6-2. 브랜드 결산 (하늘색 배경)

제목 옆에 기간을 작게 붙인다 — `2026 상반기 당근 커뮤니티 결산` + `2026. 01 - 2026. 06 기준`.
왼쪽에 가장 큰 수치 하나(`MAU 1,000만 +`)를 두고 그 아래 받쳐 주는 수치 둘(`모임 개수 +74%`, `가입자 수 +128%`)을 같은 줄에 적는다. 맨 아래 연령대 분포를 가로 띠 하나로 눕히고 칸마다 비율을 적는다(`14%` `26%` `27%` `23%` `8%`).
오른쪽은 지표 세 개를 가로선으로 나눠 쌓고 각각 아이콘을 붙인다.

수치마다 단위를 다르게 쓴다 — `103% 증가`, `8,317만 건`, `전국 오픈`. 비율·개수·상태가 섞여도 한 줄에 같이 둔다.
