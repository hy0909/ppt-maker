# 덱 디자인 시스템
> AI 에이전트 및 팀원을 위한 슬라이드 제작 가이드.
> 이 파일을 읽은 뒤 deck.html을 수정하세요.

디자인 값(색상, 글자 크기, 모서리 반지름 등)은 `design-tokens.json` 한 곳에만 있고, 웹 렌더러(`build_html.mjs`)와 파워포인트 생성기(`build_pptx.mjs`)가 그 파일을 읽는다. 웹 디자인 시스템 화면에서 값을 수정해 저장하면 이 파일이 바뀌므로, 그 파일을 프로젝트에 덮어씌우면 된다.

## 현재 기본 디자인: 미니멀 카드 리포트 (2026-09-14 채택, 예시 덱 `examples/breezehome` 기준 · 포인트 컬러 #2F0CC5 보라 계열, 2026-09-14 변경)

`scripts/build_html.mjs`(HTML)와 `scripts/build_pptx.mjs`(PPTX)가 구현한다. 예전 디자인은 `*_classic.mjs`(초기)와 스크래치 백업(연차보고서 헤더 바 스타일)에만 남아 있다.

- **팔레트**: 배경 연회색 `--page` #E9ECF0, 카드 흰색 + 그림자 `0 2px 12px rgba(20,40,80,.07)`, `--primary` 포인트 컬러(#2F0CC5 보라, 카드 상단 띠·강조), `--primary-2` 파랑(#1E5BB8, 보조 수치 문장·그래프 선), 연파랑 틴트(`--primary-softer`, 강조 박스·TO-BE 카드), 본문 #1A2438 / 보조 #4A5568. 이모지·그라디언트 텍스트·다중 그림자 금지. Pretendard, 자간 -0.015em~-0.03em(제목).
- **본문 장표 골격**(1280×720, **좌우 여백 40px** — 사용자 원본 PPTX 기준): 아이브로우 15px(y=30, **그 장표가 속한 목차(섹션) 이름 하나만**, 오른쪽 끝 페이지 번호) → 헤드라인 **31.5pt(42px)** 검정 계열 `--title` #10141C(y=61, `**강조**` 는 같은 색 800 굵기) → 1px 구분선(y=116, 여백 안쪽 전체 너비) → lead 12pt 회색(y=143, 줄간격 150%) → 본문(카드, 리드 1줄이면 y=220 부터) → 맨 아래 배너 → 출처·각주(있을 때만). 헤더 바 없음. 표지·간지·마무리는 그라디언트 배경.
- **글자 크기·간격(원본 PPTX 와 동일하게)**: 본문 불릿 17pt·진한 색(`--text`), 카드 안 소제목 16pt 굵게·연한 회색(`--body`), 알약 제목 18pt 굵게 흰색, 배너 라벨 15pt·본문 14pt. **자간은 전부 −0.8pt**(`letter-spacing:-.8pt` / `charSpacing:-0.8`). 불릿 줄높이 1.25, 항목 사이 간격은 0.4~0.9em 에서 자동.
- **제목 규칙**(2026-09-14): 헤드라인은 **문장이 아니라 명사형으로 끝낸다** — "…세 기능으로 구성", "…24주 일정". "~한다/~합니다/~이다" 금지. 강조는 색이 아니라 굵기로만 준다.
- **번호 표기**: 목차·간지는 로마숫자 대신 **1·2·3 숫자**(목차 번호 36px 800). `meta.numbering` 은 쓰지 않는다.
- **카드 안 줄 간격**: 내용량에 맞춰 자동 조절한다(항목이 적고 짧으면 넓게, 많거나 길면 좁게 — `listGap()` / `listGapEm()`). 카드 경계를 넘지 않는 선에서 위아래로 고르게 퍼뜨린다(`.fill{justify-content:space-evenly}`).
- **카드**(2026-09-14 2차 개정, 사용자 원본 PPTX 기준): **알약 제목 + 흰 본문 박스 두 덩어리**. 제목은 카드 너비 전체를 차지하는 완전히 둥근 알약(`border-radius:999px`, 포인트 컬러 채움, 흰 굵은 글씨 가운데, 글자 = 카드 제목 크기(26px), 높이 ≈ 글자 × 1.95 ≈ 51px). 알약 아래 **0.3em(≈7px) 간격**을 두고 흰 본문 박스(라운드 19px, 그림자, 안쪽 여백 `.95em 1.4em 1em`, overflow hidden). 바깥 `.card` 래퍼는 투명. stat·비교(side) 카드도 같은 구조. 카드 안 소제목은 굵은 글씨만 쓰고 **왼쪽 세로선을 붙이지 않는다**. 강조 카드는 본문만 연한 톤(`tint`).
- **카드 안 글자 위계**(원본 PPTX 기준): 소제목 = 연한 회색 굵은 글씨(`--body` #515B75, 16pt), 본문·불릿 = 진한 색(`--text` #1A2438, 17pt). `k:v` 항목의 v 는 연한 색. 줄 간격은 남는 높이에 맞춰 자동(`fit_slides.mjs` 2단계 + `listBox` availH): 넘치지 않으면서 흰 여백이 남지 않게, 최소 0.4em ~ 최대 0.9em(배너 안은 0.5em 까지).
- **지표 카드**: 왼쪽 2행 표(라벨 열 연회색, 마지막 행 굵게) + 오른쪽 연파랑 강조 박스(작은 라벨 + 큰 수치 "18% 증가"). **큰 수치(stat)**: 작은 지표명 → 큰 숫자(단위는 절반 크기) → 파란 보조 문장.
- **그래프(chart)**: 카드 안 연회색 패널, 왼쪽 제목·오른쪽 "단위 : …", 꺾은선(파랑, 점 + 값 라벨) 또는 막대. 같은 종류 그래프는 형식 통일.
- **표**: 헤더 행 연회색·굵게, 첫 열 연회색 라벨, 셀 1px 연한 선, 강조 열은 헤더 네이비 + 셀 연파랑·네이비 굵게.
- **배너(callout)**: 네이비 톤 둥근 박스(`--banner`, 포인트 컬러를 #1E2850 쪽으로 82% 섞음 ≈ #202859). **라벨("특이사항"/"참고"/"핵심 요약")은 박스 안 왼쪽**에 연한 컬러(`--banner-label`) 15pt 굵게, 본문 불릿은 오른쪽에 한 단계 죽인 톤(`--banner-text`) 14pt. 밖으로 걸치는 흰 칩은 쓰지 않는다. 배너는 **낮게** 쓴다: 안쪽 여백 `.75em 1.6em`(small 기준), 라벨–본문 간격 1.6em, 줄 사이 ≤0.35em.
- **비교(compare)**: 라벨 칩(AS-IS 회색 / TO-BE 네이비)이 달린 두 카드, 오른쪽 연파랑, 가운데 › 화살표. **로드맵**: 선 + 네이비 번호 원 + 흰 단계 카드(마지막 `darkLast` 반전). **이미지**: 흰 카드 안, 없는 이미지는 점선 자리표시자.
- **표지/마무리**: `meta.coverBg` 로 고른 배경 3종 중 하나(soft·grid·band). 표지는 설명줄 → 제목 → 왼쪽 아래 로고 → 오른쪽 아래 상자 네 덩어리만 쓴다. 자세한 좌표는 아래 '표지·목차 글자 규격'.
- **목차**: 연회색 배경(`--page`). 왼쪽 위에 `목차`(h1), 오른쪽에 **번호(1·2·3) + 섹션명(h2)** 을 2열로 적는다 — 쪽수·설명·로고는 넣지 않는다. 부록이 있으면 마지막 항목을 `+ 부록` 으로(글씨는 Paperlogy 4 Regular). 맨 아래 문서 제목 + 페이지 번호.
- **간지**: 118° 포인트 컬러 그라디언트 전면 배경(고른 표지에 짝이 되는 그림이 있으면 그 그림). 왼쪽 위 `CHAPTER 0N`(흰색 62%, 자간 넓게) → 섹션명 60px 800 흰색. `section.subtitle` 이 있으면 18px 한 줄. 오른쪽 아래에 흰 가로 로고를 12% 불투명도 워터마크로 깔고, 맨 아래 문서 제목 + `N/Mp`. 목차가 3개 이상이면 자동으로 들어간다(`meta.dividers`).
- **글자 크기**: 본문 카드만 `--k`(fit_slides) 배율. 아이브로우·헤드라인·lead 는 고정.

## 표지·목차 글자 규격 (2026-09-18 확정, 사용자 원본 PPTX 기준)

**줄 간격은 배수가 아니라 pt 고정값**이고, **자간도 pt 값**이다. 그대로 지킨다.
값은 `scripts/lib/common.mjs` 의 `TYPE` 한 곳에만 적혀 있고 HTML·PPTX 가 같이 읽는다.

| 이름 | 글꼴 | 크기 | 줄 간격 | 자간 | 쓰는 곳 |
| --- | --- | --- | --- | --- | --- |
| h0 | Paperlogy 7 Bold | 48pt | 고정 58.6pt | −1pt | 표지 제목 |
| h1 | Paperlogy 7 Bold | 40pt | 고정 48pt | −1pt | 목차 제목 `목차` |
| h2 | Paperlogy 5 Medium | 22pt | 고정 31.8pt | −0.2pt | 목차 항목 |
| body2 | Pretendard Light | 18pt | 고정 26.6pt | −0.8pt | 표지 설명줄 |

본문 안쪽 글자는 읽는 방식(dense·airy)에 상관없이 같은 값을 쓴다.
본문 18px, 작은 글 16px, 카드 제목 26px, 큰 수치 34px, 표 16px, 칸 사이 12px 이다.
장표마다 넘치지 않게 `fit_slides` 가 배율을 따로 매기므로, 두 방식의 차이는 배율 상한에만 남는다.

Paperlogy·Pretendard 는 굵기마다 패밀리 이름이 따로 있다(`Paperlogy 7 Bold`, `Pretendard Light`).
그래서 **bold 속성을 켜지 않는다** — 켜면 PowerPoint 가 가짜 굵기를 덧씌운다.

| 제목(h0) | x 59.4, y 117, 너비 720 |

표지에는 pill·docType·기관 칸(orgs)·기간/날짜를 넣지 않는다. 상자 글자는 `meta.event`(없으면 `docType`).

섹션명이 274.5px 를 넘으면 두 줄로 내려가고, 그만큼 **두 열의 다음 줄이 같이** 내려간다.
몇 줄이 되는지는 어림잡지 않고 빌드할 때 브라우저에서 같은 글꼴로 실제로 재서 HTML·PPTX 를 맞춘다.

### 출처·각주 (`slide.source` · `slide.footnote`)

제출용 제안서와 보고서는 수치에 근거를 달라고 요구한다. 그래서 본문 장표 맨 아래에 자리를 잡아 뒀다.

| 항목 | 값 |
| --- | --- |
| 자리 | 왼쪽 여백부터 오른쪽 여백까지, 아래에서 13px |
| 글자 | 11pt, 줄간격 15.4pt, 자간 -0.2, `--text-light` |
| 본문 여백 | 출처가 없으면 아래 44px. 줄이 늘면 그만큼 본문을 위로 올린다 |

- `footnote` 는 한 줄에 하나씩, `source` 는 여럿이어도 ` · ` 로 묶어 **한 줄**로 적는다. 각주가 먼저, 출처가 뒤.
- `source` 앞에 `출처: ` 를 자동으로 붙인다. 이미 적혀 있으면 덧붙이지 않는다.
- 둘 다 문자열 하나도 되고 배열도 된다.
- 값이 없으면 자리 자체가 생기지 않는다. 빈 줄이 남지 않는다.
- **원문에 없는 출처를 지어내지 않는다.** 근거가 필요한데 사용자가 주지 않았으면 `[출처 필요]` 로 남긴다.

```json
{ "headline": "…", "source": "통계청 「2025 가구 에너지 통계」, 2026.03" }
{ "headline": "…", "footnote": "* 반올림으로 합계가 100%가 아닐 수 있음",
  "source": ["내부 집계 (2026.08.01~08.31)", "네이버 데이터랩"] }
```

### 표지 배경 (`meta.coverBg`)

목록은 `assets/cover-bg/index.json` 한 곳에만 있다. 지금 들어 있는 것:

| 값 | 그림 | 파일 | 짝이 되는 간지 배경 |
| --- | --- | --- | --- |
| `cube`(기본) | 반사 있는 유리 큐브 | `cube.jpg` | 없음 |
| `stripe` | 가로 스캔라인 그라데이션 | `stripe.png` | 없음 |
| `haze` | 양옆 파란 빛 | `haze.png` | `haze-divider.png` (보라 점 그라데이션) |
| `cctv` | 감시 카메라, 도트로 덮인 | `cctv.jpg` | 없음 |
| `wave` | 보라 물결 | `wave.png` | 없음 |
| `cube-mono` | 큐브 흑백 하프톤 | `cube-mono.png` | 없음 |
| `ring` | 남색 바탕에 퍼지는 파란 동심원 | `ring.png` | 없음 |

- 표지에 짝이 되는 간지 그림(`divider`)이 있으면 **간지 배경도 그 그림으로 바뀐다**. 짝이 없으면 간지는 지금처럼 포인트 컬러 그라데이션이다.
  마무리 장표는 표지와 무관하게 늘 브랜드 그라데이션(`closingBgCss`).
- 간지 그림을 쓰면 오른쪽 아래 로고 워터마크는 넣지 않는다 — 그림이 이미 그 자리를 채운다.
- 간지 글씨는 왼쪽에 몰려 있어 `DIVIDER_SCRIM` 은 왼쪽 74% → 오른쪽 6% 로 눕힌다. 표지용 `COVER_SCRIM` 보다 왼쪽이 진하다.
- 그림 위에 제목 자리를 눌러 주는 그라데이션(`COVER_SCRIM`)을 한 겹 깐다 — 왼쪽 48% → 74% 에서 사라진다.
  제목이 길어 밝은 데 걸쳐도 흰 글씨가 읽힌다. 바탕이 검정인 그림에서는 보이지 않는다.
- HTML 은 그림 + CSS 그라데이션, PPTX 는 둘을 합쳐 한 장(`_bg_cover`)으로 캡처해 깐다.
  **원본이 PNG 면 합친 것도 PNG** 로 저장한다 — 줄무늬·경계가 뚜렷한 그림은 JPEG 에서 링잉이 생긴다.
- 작업 폴더 `out/assets/cover-bg/` 에 같은 이름 파일이 있으면 그쪽을 쓴다(그림 교체용).

### 배경을 새로 넣거나 바꿀 때 — 반드시 이 스크립트로

```bash
python3 skills/ppt-maker/scripts/prepare_cover_bg.py <원본이미지> <키> --label "화면에 보일 이름" [--replace 바꿀키]

# 표지 목록에 새로 넣지 않고, 그 표지를 골랐을 때 쓸 간지 배경으로 달 때
python3 skills/ppt-maker/scripts/prepare_cover_bg.py <원본이미지> <키> --divider-of <표지키>
```

원본을 그대로 넣지 않는다. 화면은 1280×720 인데 레티나·PDF·PPTX 확대까지 버티려면 **2560×1440** 이 필요하고,
그냥 늘리면 그림 종류에 따라 뭉개진다. 스크립트가 종류를 먼저 재고 맞는 방법을 고른다.

| 종류 | 어떻게 알아보나 | 키우는 방법 | 저장 |
| --- | --- | --- | --- |
| 줄무늬 | 가로줄(또는 세로줄)마다 색이 같다 | 줄 색만 1차원으로 늘린다. 늘어나는 방향이 하나라 흐려질 데가 없다 | PNG 무손실 |
| 디더 격자 | 색이 8개 이하이고, 정사각 칸마다 켜짐/꺼짐만 있다 | 칸 격자를 찾아 **큰 크기로 다시 그린다**. 늘리는 게 아니라 새로 그리는 것이라 점이 완전히 또렷하다 | PNG 무손실 |
| 그래픽 | 고유색 4096개 이하이고 고주파가 적다 | 선형광 Lanczos | PNG 무손실 |
| 사진·하프톤 | 그 밖 | 선형광 Lanczos + 언샵(2.0 / 75%) — 점을 다시 세운다 | JPEG 95 · 4:4:4 |

- 크기를 바꿀 때는 **선형광(감마 보정)** 에서 섞는다. 어두운 그라데이션의 밝기가 틀어지거나 띠가 지는 것을 막는다.
- 하프톤에 JPEG 4:2:0 이나 낮은 품질을 쓰지 않는다. 고주파가 많아 링잉이 보인다. **4:4:4 고정**.
- 무손실이 더 작으면 언제나 무손실을 고른다(스캔라인 그림은 PNG 20KB, JPEG 480KB 였다).
- 끝나면 **되돌림 PSNR** 을 찍는다 — 키운 그림을 원본 크기로 되돌려 원본과 비교한 값. 40dB 넘으면 눈으로 차이가 없다.
  디더 격자는 늘린 게 아니라 새로 그린 것이라 픽셀끼리 맞대는 PSNR 이 뜻이 없다. 대신 원본 칸이 얼마나 또렷하게 켜짐/꺼짐으로 갈렸는지를 찍는다.
- 회색조 그림은 고유색이 많아야 256개라 색 수만 보면 늘 '그래픽' 으로 잘못 걸린다. 그래서 종류를 가릴 때 **고주파 비율**(256×256 블록의 주파수 에너지 중 높은 쪽 절반)을 같이 본다.
  블록은 그림 전체를 격자로 훑어 **가장 높은 값**을 쓴다. 주인공이 한쪽에 치우친 그림은 가운데만 보면 텅 빈 바탕을 재게 된다.
- 고주파 기준은 0.25 로 넉넉히 잡아 애매하면 '그래픽' 쪽으로 보낸다. 그래픽 경로는 무손실이라 잘못 보내도 잃는 게 없지만,
  반대로 매끈한 그라데이션에 언샵·JPEG 를 물리면 경계에 흰 테가 생기고 띠가 진다.
- 그래도 자동 판별이 틀리면 `--kind stripe-h|stripe-v|dither|graphic|photo` 로 직접 지정한다.
- 스크립트가 `index.json` 까지 고쳐 주므로 코드는 건드릴 것이 없다.


### 장표 렌더를 배경으로 받을 때 — 글자부터 지운다

사용자가 **글자·로고가 얹힌 완성 장표**를 배경 후보로 주면, 먼저 글자를 지우고 배경만 남긴 뒤 위 스크립트에 넣는다.

```bash
python3 skills/ppt-maker/scripts/strip_cover_text.py <표지렌더> <내보낼파일> [--slope auto|none|숫자]
python3 skills/ppt-maker/scripts/prepare_cover_bg.py <내보낸파일> <키> --label "이름"
```

지울 자리는 `COVER_BOX` 가 정해 둔 리드·제목·로고·오른쪽 아래 상자 네 덩어리라 따로 찾을 것이 없다.
메우는 방법은 배경이 어떻게 생겼는지에 달렸다.

| 배경 생김새 | 메우는 방법 | 옵션 |
| --- | --- | --- |
| 매끈한 그라데이션 | 둘레 색을 안쪽으로 이어 붙인다(라플라스) | `--slope none` |
| 대각선 띠가 있다 | 띠 방향으로 양쪽 끝까지 걸어 나가 만난 두 색을 거리로 섞는다 | `--slope auto` 또는 기울기 숫자 |

띠를 가로질러 색을 섞으면 경계가 뭉개진다. 오른쪽 아래 상자 밑으로 띠 경계가 지나가는 장표가 그런 경우로,
둘레 색을 그냥 이어 붙이면 그 자리만 뿌옇게 번진다. 띠 방향으로 메우면 경계가 그대로 이어진다.
기울기는 `--slope auto` 가 잰다 — 기울기를 조금씩 바꿔 가며 비스듬히 자른 가로줄을 뽑고, 줄 안의 색이
가장 고른 기울기를 고른다. 이때 **그림 안에 온전히 들어오는 줄만** 센다. 줄이 그림 밖으로 나가면 표본이 줄어
편차도 같이 작아져서, 그냥 재면 늘 가파른 기울기가 이긴다.

- **본문**은 `c-dark`(=`--ink` 슬레이트) 또는 `c-muted`(--g6).
- **다크 슬라이드**는 `style="background:var(--dark)"`(navy) + 흰색 텍스트(`c-white`). `#0F172A` 같은 거의-검정 배경 금지.
- 강조 숫자·아이콘도 `--primary`(브랜드 블루).
- **헤더 바(claude-ppt-guide 연차보고서 스타일)**: 본문 장표 상단에 64px 높이 `--primary` 띠. 좌측 반투명 태그(`rgba(255,255,255,.12)` 배경, 12px 굵게, `i · 2` 로마숫자·장표 순번), 이어서 장 제목 20px 굵게 흰색 + 부제 13.5px(흰색 78%), 우측 끝 흰 로고 20px. 그 아래 본문은 기존 디자인(제목 h2 → 리드 박스 → 블록) 그대로. 예전 아이브로우(— 1. 섹션명)와 우상단 로고는 헤더 바로 대체되어 사용하지 않는다.

## 3. 레이아웃 안전 여백

슬라이드 크기: **1280 × 720px** (16:9 고정)

```
┌──────────────────────────────────────────────────────────┐  y=0
│  ██ .logo-wrap  top:26px, height≈26px → 하단 y=52px       │
│ ─────────────── --safe-top: 76px ──────────────────────── │  y=76  ← 콘텐츠 시작
│                                                           │
│  LEFT --pad: 52px ←──────────────────────→ RIGHT --pad   │
│                                                           │
│ ─────────────── --safe-bottom: 52px ───────────────────── │  y=668 ← 콘텐츠 끝
│  .pg  bottom:22px                                        │
└──────────────────────────────────────────────────────────┘  y=720
```

**황금 규칙**: `position:absolute;inset:0` 콘텐츠 컨테이너는 **반드시**:
```html
padding: var(--safe-top) var(--pad) var(--safe-bottom)
```
`padding:var(--pad)` 단독 사용 금지 — 상단은 로고(y=26~52), 하단은 페이지 번호(y=698~720)와 겹칩니다.

**커버/일러스트 이미지**: 반드시 `object-fit:contain` 사용. `cover`는 이미지 잘림 발생.
```html
<img src="assets/cover.png" style="width:100%;height:auto;object-fit:contain;display:block;">
```

| `::before` content 장식 | 실제 `<span>` 태그 사용 |

### `.no-print` — PDF 탈출구
원칙은 위 패턴 **금지**다. 그러나 화면 연출용으로 꼭 써야 한다면 `class="no-print"`를 붙여
인쇄(PDF)에서만 숨긴다. deck.html에 `@media print { .no-print { display:none !important; } }` 내장.

- 대상: `mask-image`, mesh·grid `background-image`(격자 인쇄됨), 장식용 glow `box-shadow`(사각 음영),
  `background-clip:text` 그라디언트(깨짐 → 단색 fallback 별도 제공).
- **콘텐츠(텍스트·핵심 도형)에는 절대 쓰지 말 것** — PDF에서 사라진다. 순수 장식 전용.

## 8. AI 에이전트 체크리스트

슬라이드를 추가하거나 수정한 후 반드시 확인:

- [ ] 이모지가 있는가? → SVG 아이콘으로 교체
- [ ] 로고가 텍스트인가? → img 태그로 교체
- [ ] `--safe-bottom` 없이 `bottom:0` 컨테이너를 썼는가? → padding-bottom 52px 이상 확보
- [ ] 빈 `img-ph` 자리표시자가 있는가? → 실제 이미지 또는 슬라이드 삭제
- [ ] 슬라이드 여백이 절반 이상인가? → 레이아웃 재설계
- [ ] 한 슬라이드에 4개 이상 bullet이 있는가? → 2–3개로 압축
- [ ] 임의 hex 색상을 썼는가? → CSS 변수로 교체
- [ ] PDF 금지 CSS를 썼는가? → 위 표 참고하여 수정
- [ ] 페이지 번호가 커버(01, 02)에 있는가? → 제거
