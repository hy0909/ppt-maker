# 입력 수집 질문 스크립트

한 번에 다 묻지 않는다. **1단계(공통) → 2단계(유형별) → 아웃라인 초안 → 확인** 순서로, 사용자가 이미 준 정보는 다시 묻지 않는다.
원문 텍스트나 기존 PPTX에서 추론할 수 있는 항목은 추론값을 내놓고 맞는지만 확인받는다.

## 1단계. 공통 (필수 항목만)

| 항목 | 질문 | 기본값 |
| --- | --- | --- |
| 모드 | 텍스트로 새로 만들까요, 기존 PPTX를 고칠까요? | 파일을 붙이면 고치기 |
| 목적 | 제안서 / 보고서 / 소개서 중 무엇인가요? | 원문에서 추론 후 확인 |
| 문서 유형 | 그 안에서 어떤 것인가요? (아래 6가지) | 원문에서 추론 후 확인 |
| 제출 조건 | 자유 양식인가요, 분량·목차가 정해진 지정 양식인가요? | 자유 양식 |
| 읽는 방식 | 발표하며 보여 주나요, 제출해서 읽히나요? | 유형별 기본값 |
| 메인 컬러 | 브랜드 메인 컬러 hex? (보조 컬러는 선택) | `#2F0CC5`. 군·공공 제출용이면 네이비 `#002060` 제안 |
| 로고 | 로고 파일이 있나요? 없으면 로고 자리를 비웁니다 | 없음 |
| 표지 배경 | 유리 큐브 / 스캔라인 / 양옆 파란 빛 / 감시 카메라 도트 / 보라 물결 / 큐브 흑백 중에서 | 유리 큐브 |
| 표지 정보 | 회사명, 발표자, 날짜, 오른쪽 아래 상자에 넣을 행사·사업명 | 원문에서 추출 |

### 문서 유형 6가지
| 목적 | 유형 | 키 | 읽는 방식 기본값 |
| --- | --- | --- | --- |
| 제안서 | 정부 과제 제안서 | `gov-proposal` | 제출·열람용 |
| 제안서 | 고객사 제안서 | `client-proposal` | 제출·열람용 |
| 보고서 | 연차보고서 | `annual-report` | 제출·열람용 |
| 보고서 | 내부 진행보고 | `internal-report` | 발표용 |
| 소개서 | 회사 소개서 | `company-intro` | 발표용 |
| 소개서 | IR (투자자) | `ir` | 발표용 |

읽는 방식은 밀도로 바뀐다 — 발표용 `airy`, 제출·열람용 `dense`.
지정 양식이면 **분량·목차 제한을 먼저 받아 적고** 그 안에서 섹션을 줄인다.

## 2단계. 유형별 추가 질문

### 정부 과제 제안서 (`gov-proposal`)
1. 공고명과 과제명은?
2. 발주처 요구사항 원문이 있나요? (표로 정리해 대응 기술과 짝지어 둡니다)
3. 핵심 기술 모듈은 몇 개이고 이름은? (모듈당 1장)
4. 시연 자료(영상 링크, 화면 캡처)가 있나요?
5. 기대효과 수치와 그 근거는? 없으면 정성 효과만 씁니다.
   수치를 쓰면 출처를 어디로 적을지도 같이 받습니다(장표 아래에 한 줄로 들어갑니다).
6. 공고문에 목차나 분량 제한이 있나요?

### 고객사 제안서 (`client-proposal`)
1. 고객사명과 제안명은?
2. 고객 현장 정보와 겪고 있는 문제는?
3. 넣을 솔루션·제품은 몇 개인가요? (하나당 1~2장)
4. 유사 프로젝트 수행 사례가 있나요? (어디에 넣었고 결과가 어땠는지)
5. 견적·구축 일정·유지보수 범위(보증, 장애 대응)가 있나요?
6. ROI 를 넣는다면 KPI 목표치와 측정 방법은?
7. 기존 제안서 PPTX 가 있나요? 있으면 고객이 바뀌어도 그대로인 장표는 살립니다.

### 연차보고서 (`annual-report`)
1. 과제명, 기간, 주관·참여기관, 이번 보고 차수는?
2. 연차 목표 대비 실적표(정량 지표)가 있나요?
3. 사업비 집행 자료가 있나요?
4. 증빙 파일(시험성적서, 인증서, 특허, 전시회 사진)이 있나요? 파일명은 `[페이지]_[이름]_[순번].png` 규칙으로 받습니다.
   증빙이 붙는 장표는 출처(시험기관·성적서 번호·집계 기간)를 같이 받아 장표 아래에 적습니다.
5. **표를 만들 때 강조할 열은 무엇인가요?** (보통 달성현황·집행률)
6. 차년도 계획과 사업화 로드맵이 있나요?

### 내부 진행보고 (`internal-report`)
1. 보고 대상(경영진, 협력사)과 목적은?
2. 이번 기간에 다룰 과제 범위는?
3. 마일스톤 단위는 주 단위인가요, 월 단위인가요?
4. 개발 인원 현황이 있나요?
5. 이번에 결정받아야 할 사항(인력·예산·일정)은?

### 회사 소개서 (`company-intro`)
1. 인원 구성, 거점, 연락처는?
2. 연혁(연도별 계약·선정·투자)이 있나요?
3. 솔루션·제품은 몇 개인가요? 각각 특징 3가지와 적용 산업은?
4. 매출, R&D 수주와 잔고, 성장률 수치가 있나요?
5. 특허 등록·출원 현황이 있나요?
6. 대표 이력과 조직 구성은?

### IR 투자자 (`ir`)
1. 한 문장으로 무엇을 하는 회사인가요?
2. 올해 매출, 수주 잔고, 고객 증가 수치가 있나요? (없으면 그 장표를 뺍니다)
3. 솔루션을 받치는 핵심 기술 5종을 꼽아 주세요.
4. 3개년 매출 목표와 확보 전략은?
5. 이번 라운드 금액과 사용처, 다음 라운드 계획은?
6. 잠재 인수자와 접근 방법을 적을까요?
7. 대표·CTO 이력과 조직 구성은?

## 기존 PPTX 개선 모드 추가 질문
1. 개선 방향을 골라 주세요(복수): 가독성 / 디자인 통일 / 장표 흐름 / 텍스트 요약 / 표·그래프 단순화
2. 내용은 그대로 두고 디자인만 바꿀까요, 문장도 다듬을까요? (수치는 어떤 경우에도 바꾸지 않음)
3. 추출된 장표 → 템플릿 매핑표를 보여 드립니다. 누락 섹션을 추가할지, 남는 장표를 유지/부록/삭제할지 골라 주세요.

## 아웃라인 확인 단계에서 보여줄 것
- 섹션 목록과 장표 수
- 장표별 제목 + 리드 메시지 한 줄 + 블록 타입
- `[입력 필요]`로 남긴 자리 목록
- 표가 있으면 강조 열 제안

사용자가 "좋다"고 하면 빌드. 수정 요청은 아웃라인에 반영해 다시 보여준다. 빌드 후 미리보기를 보며 피드백을 받을 때도 수정 대상은 항상 아웃라인이다.
